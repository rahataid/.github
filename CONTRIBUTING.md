# Contribute 

Welcome to Rahat! To learn more about contributing to the Rahat Aid code repo, check out the <a href="https://docs.rahat.io/community/contribution-guidelines" target="_blank">Contributor's Guide</a>.

The Rahat platform is an open-source project working to create an environment where our community can effectively explore and create innovative, open aid distribution technology services that are inclusive, accountable, and accessible for everyone.

The Rahat community repo contains information about how to get started, how the community organizes, and more.
